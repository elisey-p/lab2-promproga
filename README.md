\# Лабораторная работа №2: Git Workflow



\## Описание проекта

Программа демонстрации алгоритмов сортировки на языке C.



\## Алгоритмы

1\. Сортировка вставками

2\. Сортировка выбором

3\. Пузырьковая сортировка с флагом

4\. Сортировка Шелла

5\. Шейкерная сортировка



\## Git Flow

\- `main` - стабильная версия

\- `develop` - разработка

\- `feature/\*` - новые возможности



\## Автоматизация (Git Hooks)



\### Pre-commit

Проверяет код перед коммитом:

\- ✓ Отсутствие табуляций

\- ✓ Отсутствие trailing spaces

\- ✓ Контроль длины строк



\### Post-commit

Автоматически логирует все коммиты в `commit.log`
